      호환성 진단 및 설정 복구

      SillyTavern 공개 API·모델 컨트롤·중복 런타임 자원을 검사하고, 민감정보를 제외한 확장 설정만 백업합니다.

        지원 범위 및 개인정보

        v0.6은 SillyTavern과 외부 확장이 기존 Chat Completion 연결 및 요청 규격을 그대로 사용하는 모델 ID를 지원합니다. 범용 연결은 모델 컨트롤에 선택지를 추가하고 확장 자체의 저장 이벤트를 사용하며 전역 fetch를 가로채지 않습니다. 라우팅과 백업에는 모델 참조, 외부 컨트롤 식별자 및 Connection Profile ID만 저장하고 API 키, Service Account, 프로젝트 ID, 리전, 엔드포인트 URL은 읽거나 저장하지 않습니다.
