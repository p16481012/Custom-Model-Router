    연결 상태 설명 보기
    자동으로 연결됨
    CMR이 제공업체를 찾아 등록 모델을 표시하는 연결 방식입니다.
    직접 지정
    사용자가 고른 제공업체의 등록 모델을 표시하는 연결 방식입니다.
    설정 필요
    제공업체를 판단하지 못해 아직 해당 입력란을 변경하지 않은 상태입니다.
    연결 안 함
    사용자 설정에 따라 CMR이 해당 모델 입력란을 변경하지 않는 상태입니다.

      안전 안내 채팅 모델이 아닌 임베딩·음성·이미지 생성용 입력란은 변경하지 않습니다. 아직 확인하지 않았습니다.

      기능별 모델 지정 CMR 연동을 지원하는 보조 기능에 별도 모델을 지정합니다.

      CMR Registry/Routing API 연동을 지원하는 기능에서 등록 모델과 연결 프로필을 묶어 사용합니다. 기존 번역·요약 확장에 자동 적용되지는 않으며, 기본 채팅 모델도 바뀌지 않습니다.

      선택한 모델과 같은 제공업체의 Chat Completion 프로필만 사용할 수 있습니다.
      연결 테스트는 실제 API 사용량이 발생할 수 있습니다.
      문제 확인 및 설정 백업 작동 상태를 확인하거나 CMR 설정만 백업·복원합니다.

      문제 확인

      버전, 모델 메뉴 연결과 중복 실행 여부를 확인합니다.

      CMR 설정 백업

      등록 모델, 기능별 지정과 다른 확장 연결 설정만 저장하며 API 키와 연결 주소는 포함하지 않습니다.

        지원 범위 및 개인정보
        • 지원: 기존 Chat Completion 연결과 요청 규격을 그대로 사용하는 모델 ID
        • 외부 확장: 모델 입력란에 선택지를 추가하고 해당 확장의 저장 이벤트를 사용
        • 저장: 모델 참조, 외부 입력란 식별자, 연결 방식과 Connection Profile ID
        • 저장하지 않음: API 키, Service Account, 프로젝트 ID, 리전, 엔드포인트 URL
        • 별도 지원 필요: 표준 모델 입력란이 없거나 기존 Chat Completion 규격과 다른 확장
