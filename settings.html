      목록은 외부 확장의 화면 변경을 감지해 자동으로 갱신됩니다. 임베딩, TTS, 이미지 생성 등 Chat Completion이 아닌 대상은 안전을 위해 제외합니다.
      호환성 진단 및 설정 복구

      SillyTavern 공개 API·모델 컨트롤·중복 런타임 자원을 검사하고, 민감정보를 제외한 등록 모델과 API 연동 설정을 백업합니다.

        지원 범위 및 개인정보

        SillyTavern과 외부 확장이 기존 Chat Completion 연결 및 요청 규격을 그대로 사용하는 모델 ID를 지원합니다.

        감지된 표준 Chat Completion 모델 컨트롤에는 등록 모델 전체를 제공업체별로 추가합니다. 자체 위젯이나 비채팅 모델 컨트롤은 변경하지 않습니다. 전역 fetch를 가로채지 않습니다.

        공개 API와 백업에는 모델 참조, 외부 컨트롤 식별자 및 Connection Profile ID만 저장합니다. API 키, Service Account, 프로젝트 ID, 리전, 엔드포인트 URL은 읽거나 저장하지 않습니다.
