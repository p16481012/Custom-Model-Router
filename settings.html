          문제가 생긴 모델 칸 제외

          CMR은 실제 요청 결과까지 자동으로 확인할 수 없습니다. 외부 기능에서 문제가 생긴 모델 칸만 선택해 제외하세요.

            선택지가 보인다는 사실과 실제 요청에 해당 모델이 사용된다는 사실은 다릅니다. 실제 기능을 한 번 실행한 뒤 요청 또는 결과를 확인하세요.
            지원 범위 및 개인정보

            SillyTavern과 외부 확장이 기존 Chat Completion 연결 및 요청 규격을 그대로 사용하는 모델 ID를 지원합니다.

            감지된 표준 Chat Completion 모델 컨트롤에는 native option과 중복되지 않는 등록 모델을 target별 최대 512개까지 제공업체별로 추가합니다. 자체 위젯이나 비채팅 모델 컨트롤은 변경하지 않습니다. 전역 fetch를 가로채지 않습니다.

            공개 API와 백업에는 모델 참조, 외부 컨트롤 식별자 및 Connection Profile ID만 저장합니다. 진단·백업에는 API 키, Service Account, 프로젝트 ID, 리전, 엔드포인트 URL을 포함하지 않으며 CMR 설정에 복제해 저장하지 않습니다.
